# Decision log

Short record of product and technical decisions, newest first.

## 2026-10-10: iOS is the first mobile platform

- The team all uses iOS. Android is not needed for the first release.
- Implication: pick a stack that is strong on iOS. Options are native
  SwiftUI, React Native (Expo), or a responsive web app wrapped as a PWA.
- Open: whether the app is for the team only or a product for others. That
  decides native versus cross-platform.
